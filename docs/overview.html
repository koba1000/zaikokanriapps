多層防御：どの層が何を止めるか

1つの層をすり抜けても、次の層で止まる
層場所止めるもの
L1 AI指示.github/copilot-instructions.mdSQL連結・|safe・認可なしルートをそもそも書かせない。TDDを指示
L2 ローカル.pre-commit-config.yaml秘密鍵/APIキーのコミット、危険なコード
L3 PRCODEOWNERS / PRテンプレ / ブランチ保護認証・暗号・CI設定をAIが勝手に変更してマージ
L4 CIci.yml / codeql.ymlテスト失敗、脆弱な依存、秘密情報、危険コード、認可宣言の漏れ
L5 デプロイrender.yamlCI未通過のデプロイ、秘密情報のリポジトリ混入
L6 実行時app/ 全体未認証アクセス、権限逸脱、CSRF、XSS、総当たり、DB漏えい時の住所閲覧
L7 事後audit.py / 監査ログ画面不正操作の追跡（誰が住所・売上を見たか）
核となる2つ： ①デフォルト拒否の関所（宣言のないルートは403）　②認可ハーネス（全ルートを自動列挙して検査。新ルートも自動で対象）
